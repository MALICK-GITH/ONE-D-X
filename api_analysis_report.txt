1. CONFIGURATION DE L'API
═══════════════════════════════════════════════════════════════════════════════

URL BASE: https://888starz.bet/service-api/LiveFeed/Get1x2_VZip

PARAMÈTRES UTILISÉS:
• sports=85           : Sport FIFA/eSports virtuels
• count=40            : Nombre maximum d'événements retournés
• lng=fr              : Langue française pour la réponse
• gr=789              : Groupe de règles/filtre spécifique
• mode=4              : Mode de récupération des données (4 = mode étendu)
• country=96          : Code pays (probablement France)
• partner=233         : Identifiant partenaire pour tracking
• getEmpty=true       : Inclut les événements sans cotes disponibles
• virtualSports=true  : Active les sports virtuels
• noFilterBlockEvent=true : Désactive les filtres d'événements bloqués

3. SYSTÈME DE COTES
═══════════════════════════════════════════════════════════════════════════════

TYPES DE PARIS IDENTIFIÉS (Code T):

• T=1  : Victoire Équipe 2 (Outsider)     Exemple: 5.54
• T=2  : Victoire Équipe 1 (Outsider)     Exemple: 5.7
• T=3  : Victoire Équipe 1 (Favorite)     Exemple: 1.355
• T=4  : Victoire Équipe 2 (Favorite)     Exemple: 2.86
• T=5  : Double Chance 1X ou 12          Exemple: 1.075
• T=6  : Double Chance X2 ou 12          Exemple: 1.08
• T=7  : Handicap Positif Équipe 1        Exemple: 1.81 (+1.5)
• T=8  : Handicap Négatif Équipe 1        Exemple: 2.0 (-1.5)
• T=9  : Over (Plus de buts/points)       Exemple: 1.67 (Over 6.5)
• T=10 : Under (Moins de buts/points)     Exemple: 2.205 (Under 6.5)
• T=11 : Équipe 1 marque plus de         Exemple: 1.765 (+2.5)
• T=12 : Équipe 1 marque moins de        Exemple: 2.06 (-2.5)
• T=13 : Équipe 2 marque plus de         Exemple: 2.495 (+4.5)
• T=14 : Équipe 2 marque moins de        Exemple: 1.51 (-4.5)

STRUCTURE D'UNE COTE:
{
  "T": 1,           // Type de pari
  "C": 5.54,        // Cote en décimal
  "CV": "5.54",     // Cote en chaîne
  "G": 1,           // Groupe (pour classification)
  "P": 2.5,         // Paramètre (handicap, seuil de buts)
  "CE": 1           // Current Event (si applicable)

4. COTES ADDITIONNELLES (HANDICAPS)
═══════════════════════════════════════════════════════════════════════════════

Les cotes additionnelles (AE) sont organisées par groupes:

• GROUPE G=2 : Handicaps sur les buts
  - Handicaps: -2.5, -2.0, -1.5, -1.0, +1.0, +1.5, +2.0, +2.5
  - Types: T=7 (positif), T=8 (négatif)
  - Exemple: Bayern +1.5 @ 1.81, Bayern -1.5 @ 2.0

• GROUPE G=17 : Handicaps sur les points/total
  - Handicaps: 5.5, 6.5, 7.5, 8.5, 9.5, 12.5, 13.5, 14.5, 15.5, 16.5
  - Types: T=9 (Over), T=10 (Under)
  - Exemple: Over 6.5 @ 1.67, Under 6.5 @ 2.205

• À venir (ICY=false): Message "Paris avant le début du jeu", temps restant
